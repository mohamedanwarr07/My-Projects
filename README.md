# Machine Learning Projects

A collection of hands-on Machine Learning projects built using Python and Scikit-learn. This repository documents my learning journey, from data preprocessing and exploratory data analysis to model training, evaluation, and optimization.

## About

I'm currently learning Machine Learning and building practical projects to develop my skills in data analysis, model development, and problem-solving.

Each project focuses on applying machine learning concepts to real-world datasets.

## Projects

### 1. Student Performance Prediction

**Type:** Regression

**Objective:** Predict students' exam scores based on different factors that may influence academic performance.

**Key concepts and techniques:**
- Exploratory Data Analysis (EDA)
- Data cleaning and missing-value handling
- Feature engineering
- Categorical encoding and numerical scaling
- Regression models
- Cross-validation and hyperparameter tuning
- Model evaluation using MAE, MSE, RMSE, and R²

### 2. Telco Customer Churn Prediction

**Type:** Classification

**Objective:** Predict whether a customer is likely to leave a telecommunications company.

**Key concepts and techniques:**
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Handling missing values
- One-Hot Encoding and Standard Scaling
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- GridSearchCV and hyperparameter tuning
- Class imbalance and threshold tuning
- Model evaluation using Accuracy, Precision, Recall, F1-score, and ROC-AUC
- Feature coefficient interpretation
